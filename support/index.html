Comment gérer ou résilier l'abonnement Premium ?

Sur iPhone : Réglages › ton nom › Abonnements › Plead It. La résiliation prend effet à la fin de la période en cours.

J'ai changé de téléphone, comment récupérer Premium ?

Dans l'app : Réglages › Plead It Premium › Restaurer mes achats, avec le même identifiant Apple. Ça marche pour l'abonnement comme pour l'achat à vie.

Comment fonctionne l'essai gratuit ?

Avec l'abonnement annuel, les 3 premiers jours sont gratuits pour les nouveaux abonnés. Si tu résilies au moins 24 h avant la fin de l'essai, rien n'est débité.

Comment jouer avec un pack thématique ?

Avec Premium, dans l'écran « Avant de jouer », touche un ou plusieurs packs : les opinions de la partie viennent alors de ces packs, à la place du niveau choisi.

Comment débloquer les opinions premium gratuitement ?

Avant une partie, regarde la courte vidéo proposée : les opinions premium sont débloquées pendant 24 heures.

Comment changer mes choix sur les publicités ?

Dans l'app : Réglages › Gérer mes choix de confidentialité (Europe). Tu peux aussi désactiver le suivi publicitaire dans Réglages › Confidentialité › Suivi de ton iPhone.

Comment effacer mes données ?

Toutes les données (joueurs, photos, scores) sont stockées sur ton téléphone. Dans l'app : Réglages › Données › Réinitialiser, ou supprime simplement l'application.
